# Planner Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Planner page with today's top 3 and daily/weekly/monthly habit tracking (grids, daily progress chart, top habits), plus Hermes commands, export/import and isolation checks.

**Architecture:** Pure date/streak/percent rules live in `shared/planner.ts`, unit-tested with vitest. Zod schemas and response types live in `shared/planner-schemas.ts`. One service, `functions/lib/services/planner.ts`, does all D1 work, scoped by `userId`. Browser routes are in `functions/lib/routes/planner.ts`, and agent routes join `functions/lib/routes/agent.ts`. The React page `src/routes/planner.tsx` composes the components in `src/components/planner/`, using TanStack Query hooks in `src/hooks/planner.ts`.

**Tech Stack:** Hono, Drizzle + D1 (drizzle-kit migrations), Zod 4, Vitest, React 19 + TanStack Query + wouter, Tailwind, Recharts via `@/components/ui/chart`, Phosphor icons, Python 3 stdlib (Hermes client).

**Spec:** `docs/superpowers/specs/2026-10-06-planner-design.md`

## Global Constraints

- Dates are Berlin calendar dates `YYYY-MM-DD`. "Today" is always `berlinToday()` on the server.
- Weeks start on Monday. Period keys: daily = the date, weekly = that week's Monday, monthly = `YYYY-MM-01`.
- Habit limits on active (non-archived) habits: daily 50, weekly 20, monthly 40. Going over returns `409 habit_limit`.
- Habit names: 1 to 80 chars, unique per user across all frequencies, ignoring case and spacing (`normalizeName`). A clash returns `409 name_taken`.
- Top 3: at most 3 tasks a day, text 1 to 200 chars, positions 1 to 3 in array order.
- Future periods can't be ticked (`400 future_period`). Past periods can.
- Archived habits are hidden from the day and month views and left out of every percentage. Their history stays in the database.
- Everything is behind the `planner` feature: `/planner/*` and `/agent/planner/*`. The `habits` feature is removed.
- Every query filters by `user_id`. Another user's id gives 404.
- The look matches the app: dark, emerald accent (`bg-primary`), `panel` card style, the existing `ChartCard` with a Table toggle. The page never scrolls sideways; grids scroll inside their card.

## Review Focus

1. A week that crosses a month or year boundary, and a date that is a Sunday. `periodFor` must return the Monday before it. Pinned in Task 2 unit tests.
2. A habit created on the 20th must not show 35% for "missing" the 1st to the 19th. Percentages count only days since creation. Pinned in Task 2.
3. Ticking or unticking twice (double click, retry) must be a no-op that returns 200, not an error. Pinned in Task 3 isolation checks.
4. Renaming a habit to an existing name in different case ("gym" vs "Gym") must return 409 `name_taken`, not create an ambiguous pair. Pinned in Task 3.
5. "did gym" when Gym is a weekly habit must tick this week, not today's date. Pinned in Task 4.

```ts
// Pure planner rules shared by the API and the UI. No zod, no I/O.
// Dates are Berlin calendar dates "YYYY-MM-DD", months "YYYY-MM". Weeks start on Monday.

import { berlinToday, daysInMonth } from "./money";

export const FREQUENCIES = ["daily", "weekly", "monthly"] as const;
export type Frequency = (typeof FREQUENCIES)[number];

export const HABIT_LIMITS: Record<Frequency, number> = { daily: 50, weekly: 20, monthly: 40 };
export const MAX_DAY_TASKS = 3;

const utc = (date: string) => new Date(`${date}T00:00:00Z`);
const iso = (d: Date) => d.toISOString().slice(0, 10);

export function addDays(date: string, n: number): string {
  const d = utc(date);
  d.setUTCDate(d.getUTCDate() + n);
  return iso(d);
}

export function mondayOf(date: string): string {
  const dow = (utc(date).getUTCDay() + 6) % 7; // Monday = 0
  return addDays(date, -dow);
}

export function periodFor(f: Frequency, date: string): string {
  if (f === "daily") return date;
  if (f === "weekly") return mondayOf(date);
  return `${date.slice(0, 7)}-01`;
}

export const isValidPeriod = (f: Frequency, period: string) => periodFor(f, period) === period;

export const isFuturePeriod = (f: Frequency, period: string, today: string) => period > periodFor(f, today);

export function daysOfMonth(month: string): string[] {
  return Array.from({ length: daysInMonth(month) }, (_, i) => `${month}-${String(i + 1).padStart(2, "0")}`);
}

export const mondaysInMonth = (month: string) => daysOfMonth(month).filter((d) => mondayOf(d) === d);

/** The Berlin calendar day an ISO timestamp falls on. */
export const createdDay = (createdAtIso: string) => berlinToday(new Date(createdAtIso));

/** Periods in a row up to now. Today's (or this week's) open period doesn't break it. */
export function streak(f: Frequency, checked: ReadonlySet<string>, today: string): number {
  if (f === "monthly") return 0;
  const step = f === "daily" ? 1 : 7;
  let p = periodFor(f, today);
  if (!checked.has(p)) p = addDays(p, -step);
  let n = 0;
  while (checked.has(p)) {
    n++;
    p = addDays(p, -step);
  }
  return n;
}

/** Share of the month's elapsed periods ticked, counting only periods since the habit existed. Null when none elapsed. */
export function habitPercent(
  f: "daily" | "weekly",
  createdOn: string,
  checked: ReadonlySet<string>,
  month: string,
  today: string,
): number | null {
  const periods =
    f === "daily"
      ? daysOfMonth(month).filter((d) => d <= today && d >= createdOn)
      : mondaysInMonth(month).filter((m) => m <= mondayOf(today) && m >= mondayOf(createdOn));
  if (periods.length === 0) return null;
  return Math.round((100 * periods.filter((p) => checked.has(p)).length) / periods.length);
}

/** For the progress chart: each day's share of daily habits ticked. Null for future days and days with no habits. */
export function dayPercents(
  habits: { id: string; createdOn: string }[],
  checks: ReadonlyMap<string, ReadonlySet<string>>,
  month: string,
  today: string,
): { date: string; percent: number | null }[] {
  return daysOfMonth(month).map((date) => {
    if (date > today) return { date, percent: null };
    const eligible = habits.filter((h) => h.createdOn <= date);
    if (eligible.length === 0) return { date, percent: null };
    const done = eligible.filter((h) => checks.get(h.id)?.has(date)).length;
    return { date, percent: Math.round((100 * done) / eligible.length) };
  });
}

export function topHabits<T extends { name: string; percent: number | null; streak: number }>(rows: T[], n = 10): T[] {
  return rows
    .filter((r) => r.percent !== null)
    .sort((a, b) => b.percent! - a.percent! || b.streak - a.streak || a.name.localeCompare(b.name))
    .slice(0, n);
}

/** "today", "this week", "the week of 2026-09-28", "2026-09"... for agent replies. */
export function periodLabel(f: Frequency, period: string, today: string): string {
  const current = period === periodFor(f, today);
  if (f === "daily") return current ? "today" : period;
  if (f === "weekly") return current ? "this week" : `the week of ${period}`;
  return current ? "this month" : period.slice(0, 7);
}
```

```ts
// Every function takes the signed-in user's id. Lookups match on (id, user_id), so another
// user's id behaves exactly like an id that doesn't exist: 404.

const newId = () => crypto.randomUUID();
const strip = <T extends { userId: string }>({ userId: _owner, ...rest }: T) => rest;

// ---- Habits -------------------------------------------------------------------

export async function listHabits(db: Db, userId: string): Promise<HabitRow[]> {
  const rows = await db.select().from(habits).where(eq(habits.userId, userId)).orderBy(asc(habits.sortOrder), asc(habits.name));
  return rows.map(strip);
}

async function getHabit(db: Db, userId: string, id: string): Promise<HabitRow> {
  const row = await db
    .select()
    .from(habits)
    .where(and(eq(habits.id, id), eq(habits.userId, userId)))
    .get();
  if (!row) throw notFound("Habit");
  return strip(row);
}

async function assertNameFree(db: Db, userId: string, name: string, exceptId?: string) {
  const clash = (await listHabits(db, userId)).find((h) => h.id !== exceptId && normalizeName(h.name) === normalizeName(name));
  if (clash) throw new ApiError(409, "name_taken", `A habit named "${clash.name}" already exists`);
}

async function assertUnderLimit(db: Db, userId: string, frequency: Frequency) {
  const row = await db
    .select({ n: count() })
    .from(habits)
    .where(and(eq(habits.userId, userId), eq(habits.frequency, frequency), eq(habits.archived, false)))
    .get();
  if ((row?.n ?? 0) >= HABIT_LIMITS[frequency]) {
    throw new ApiError(409, "habit_limit", `You can have at most ${HABIT_LIMITS[frequency]} ${frequency} habits. Archive one first.`);
  }
}

export async function createHabit(db: Db, userId: string, input: HabitCreate): Promise<HabitRow> {
  await assertNameFree(db, userId, input.name);
  await assertUnderLimit(db, userId, input.frequency);
  const all = await listHabits(db, userId);
  const row = {
    id: newId(),
    userId,
    name: input.name,
    frequency: input.frequency,
    sortOrder: all.reduce((m, h) => Math.max(m, h.sortOrder + 1), 0),
    archived: false,
    createdAt: nowIso(),
  };
  await db.insert(habits).values(row);
  return strip(row);
}

export async function updateHabit(db: Db, userId: string, id: string, patch: HabitUpdate): Promise<HabitRow> {
  const habit = await getHabit(db, userId, id);
  if (patch.name !== undefined) await assertNameFree(db, userId, patch.name, id);
  if (patch.archived === false && habit.archived) await assertUnderLimit(db, userId, habit.frequency);
  if (Object.keys(patch).length === 0) return habit;
  await db
    .update(habits)
    .set(patch)
    .where(and(eq(habits.id, id), eq(habits.userId, userId)));
  return getHabit(db, userId, id);
}

export async function deleteHabit(db: Db, userId: string, id: string) {
  await getHabit(db, userId, id);
  await db.batch([
    db.delete(habitChecks).where(and(eq(habitChecks.habitId, id), eq(habitChecks.userId, userId))),
    db.delete(habits).where(and(eq(habits.id, id), eq(habits.userId, userId))),
  ]);
}

/** Matches a spoken habit name against active habits. */
export async function findHabitByName(db: Db, userId: string, name: string): Promise<HabitRow> {
  const active = (await listHabits(db, userId)).filter((h) => !h.archived);
  const match = active.find((h) => normalizeName(h.name) === normalizeName(name));
  if (match) return match;
  throw new ApiError(404, "unknown_habit", `No habit named "${name}". Pick the closest of these, or ask.`, {
    habits: active.map((h) => ({ name: h.name, frequency: h.frequency })),
  });
}

// ---- Checks -------------------------------------------------------------------

export async function setCheck(db: Db, userId: string, habitId: string, period: string, checked: boolean, today = berlinToday()) {
  const habit = await getHabit(db, userId, habitId);
  if (!isValidPeriod(habit.frequency, period)) {
    const hint = habit.frequency === "weekly" ? "a Monday" : habit.frequency === "monthly" ? "the 1st of a month" : "a date";
    throw new ApiError(400, "invalid_period", `${habit.name} is ${habit.frequency}, so the period must be ${hint}`);
  }
  if (checked && isFuturePeriod(habit.frequency, period, today)) {
    throw new ApiError(400, "future_period", "You can't tick a period that hasn't started yet");
  }
  if (checked) {
    await db.insert(habitChecks).values({ habitId, userId, period, createdAt: nowIso() }).onConflictDoNothing();
  } else {
    await db.delete(habitChecks).where(and(eq(habitChecks.habitId, habitId), eq(habitChecks.userId, userId), eq(habitChecks.period, period)));
  }
  return { habit, period, checked };
}

/** All checks of the given habits, grouped by habit id. */
async function checksByHabit(db: Db, userId: string, habitIds: string[]) {
  const map = new Map<string, Set<string>>(habitIds.map((id) => [id, new Set<string>()]));
  if (habitIds.length === 0) return map;
  const rows = await db
    .select({ habitId: habitChecks.habitId, period: habitChecks.period })
    .from(habitChecks)
    .where(and(eq(habitChecks.userId, userId), inArray(habitChecks.habitId, habitIds)));
  for (const r of rows) map.get(r.habitId)?.add(r.period);
  return map;
}

// ---- Day ----------------------------------------------------------------------

async function listTasks(db: Db, userId: string, day: string): Promise<DayTaskRow[]> {
  const rows = await db
    .select()
    .from(dayTasks)
    .where(and(eq(dayTasks.userId, userId), eq(dayTasks.day, day)))
    .orderBy(asc(dayTasks.position));
  return rows.map(strip);
}

export async function getDay(db: Db, userId: string, date?: string, now = new Date()): Promise<DayView> {
  const today = berlinToday(now);
  const day = date ?? today;
  const active = (await listHabits(db, userId)).filter((h) => !h.archived);
  const checks = await checksByHabit(db, userId, active.map((h) => h.id));
  const view = (h: HabitRow): DayHabit => {
    const set = checks.get(h.id)!;
    return { ...h, checked: set.has(periodFor(h.frequency, day)), streak: streak(h.frequency, set, today) };
  };
  return {
    date: day,
    today,
    tasks: await listTasks(db, userId, day),
    habits: {
      daily: active.filter((h) => h.frequency === "daily").map(view),
      weekly: active.filter((h) => h.frequency === "weekly").map(view),
      monthly: active.filter((h) => h.frequency === "monthly").map(view),
    },
  };
}

export async function putDayTasks(db: Db, userId: string, day: string, tasks: { text: string; done: boolean }[]) {
  const rows = tasks.map((t, i) => ({ id: newId(), userId, day, position: i + 1, text: t.text, done: t.done, createdAt: nowIso() }));
  const del = db.delete(dayTasks).where(and(eq(dayTasks.userId, userId), eq(dayTasks.day, day)));
  if (rows.length === 0) await del;
  else await db.batch([del, db.insert(dayTasks).values(rows)]);
  return listTasks(db, userId, day);
}

export async function updateTask(db: Db, userId: string, id: string, patch: TaskUpdate): Promise<DayTaskRow> {
  const where = and(eq(dayTasks.id, id), eq(dayTasks.userId, userId));
  const row = await db.select().from(dayTasks).where(where).get();
  if (!row) throw notFound("Task");
  if (Object.keys(patch).length > 0) await db.update(dayTasks).set(patch).where(where);
  return strip({ ...row, ...patch });
}

// ---- Month --------------------------------------------------------------------

export async function getMonth(db: Db, userId: string, month?: string, now = new Date()): Promise<MonthView> {
  const today = berlinToday(now);
  const m = month ?? berlinMonth(now);
  const days = daysOfMonth(m);
  const mondays = mondaysInMonth(m);
  const active = (await listHabits(db, userId)).filter((h) => !h.archived);
  const checks = await checksByHabit(db, userId, active.map((h) => h.id));
  const created = (h: HabitRow) => createdDay(h.createdAt);

  const daily = active
    .filter((h) => h.frequency === "daily")
    .map((h) => {
      const set = checks.get(h.id)!;
      return {
        habit: h,
        checks: days.filter((d) => set.has(d)),
        percent: habitPercent("daily", created(h), set, m, today),
        streak: streak("daily", set, today),
      };
    });
  const weekly = active
    .filter((h) => h.frequency === "weekly")
    .map((h) => {
      const set = checks.get(h.id)!;
      return {
        habit: h,
        weeks: mondays.map((monday) => ({ monday, checked: set.has(monday) })),
        percent: habitPercent("weekly", created(h), set, m, today),
        streak: streak("weekly", set, today),
      };
    });
  const monthly = active.filter((h) => h.frequency === "monthly").map((h) => ({ habit: h, checked: checks.get(h.id)!.has(`${m}-01`) }));

  return {
    month: m,
    today,
    days,
    mondays,
    daily,
    dayPercents: dayPercents(daily.map((r) => ({ id: r.habit.id, createdOn: created(r.habit) })), checks, m, today),
    weekly,
    monthly,
    top: topHabits([
      ...daily.map((r) => ({ id: r.habit.id, name: r.habit.name, frequency: "daily" as const, percent: r.percent, streak: r.streak })),
      ...weekly.map((r) => ({ id: r.habit.id, name: r.habit.name, frequency: "weekly" as const, percent: r.percent, streak: r.streak })),
    ]),
  };
}
```

```ts
// Voice-agent side of the Planner. The agent sends names and plain text; this file
// matches them and writes short replies that read well in a chat.

const plural = (n: number, word: string) => `${n} ${word}${n === 1 ? "" : "s"}`;
const names = (rows: { name: string }[]) => rows.map((r) => r.name).join(", ");

export function planSpeech(day: DayView): string {
  const parts: string[] = [];
  parts.push(
    day.tasks.length === 0
      ? `No top 3 set for ${day.date === day.today ? "today" : day.date}.`
      : `Top 3: ${day.tasks.map((t) => (t.done ? `${t.text} (done)` : t.text)).join(", ")}.`,
  );
  const leftDaily = day.habits.daily.filter((h) => !h.checked);
  if (day.habits.daily.length > 0) {
    parts.push(leftDaily.length === 0 ? "All daily habits done." : `Habits left today: ${names(leftDaily)}.`);
  }
  const leftWeekly = day.habits.weekly.filter((h) => !h.checked);
  if (leftWeekly.length > 0) parts.push(`This week: ${names(leftWeekly)}.`);
  const leftMonthly = day.habits.monthly.filter((h) => !h.checked);
  if (leftMonthly.length > 0) parts.push(`This month: ${names(leftMonthly)}.`);
  return parts.join(" ");
}

export async function agentToday(db: Db, userId: string, now = new Date()) {
  const day = await getDay(db, userId, undefined, now);
  return { ...day, speech: planSpeech(day) };
}

export async function agentCheck(db: Db, userId: string, input: { habit: string; date?: string }, checked: boolean, now = new Date()) {
  const today = berlinToday(now);
  const habit = await findHabitByName(db, userId, input.habit);
  const period = periodFor(habit.frequency, input.date ?? today);
  await setCheck(db, userId, habit.id, period, checked, today);
  const label = periodLabel(habit.frequency, period, today);
  let speech = `${checked ? "Ticked" : "Unticked"} ${habit.name} for ${label}.`;
  if (checked && habit.frequency !== "monthly") {
    const day = await getDay(db, userId, undefined, now);
    const s = [...day.habits.daily, ...day.habits.weekly].find((h) => h.id === habit.id)?.streak ?? 0;
    if (s > 0) speech += ` 🔥 ${plural(s, habit.frequency === "daily" ? "day" : "week")}.`;
  }
  return { habit: habit.name, frequency: habit.frequency, period, checked, speech };
}

export async function agentSetTasks(db: Db, userId: string, input: { tasks: string[]; date?: string }, now = new Date()) {
  const today = berlinToday(now);
  const day = input.date ?? today;
  const tasks = await putDayTasks(db, userId, day, input.tasks.map((text) => ({ text, done: false })));
  return { tasks, speech: `Top 3 for ${day === today ? "today" : day}: ${tasks.map((t) => t.text).join(", ")}.` };

export async function agentTaskDone(db: Db, userId: string, input: { task: string; date?: string }, now = new Date()) {
  const day = await getDay(db, userId, input.date, now);
  const ref = input.task.trim();
  const target = /^[1-3]$/.test(ref)
    ? day.tasks.find((t) => t.position === Number(ref))
    : day.tasks.find((t) => normalizeName(t.text) === normalizeName(ref));
  if (!target) {
    throw new ApiError(404, "unknown_task", `No top-3 task "${input.task}" on ${day.date}.`, { tasks: day.tasks.map((t) => t.text) });
  }
  const task = await updateTask(db, userId, target.id, { done: true });
  const doneCount = day.tasks.filter((t) => t.done || t.id === task.id).length;
  return { task, speech: `Done: ${task.text}. ${doneCount} of ${day.tasks.length} done.` };
}
```

```ts
import { keepPreviousData, useMutation, useQuery, useQueryClient } from "@tanstack/react-query";
import { toast } from "sonner";
import { periodFor, type Frequency } from "@shared/planner";
import type { DayView, MonthView } from "@shared/planner-schemas";
import { plannerApi } from "@/lib/planner-api";

export const plannerKeys = {
  all: ["planner"] as const,
  day: (date: string) => ["planner", "day", date] as const,
  month: (month: string) => ["planner", "month", month] as const,
  habits: ["planner", "habits"] as const,
};

export const useDay = (date: string) =>
  useQuery({ queryKey: plannerKeys.day(date), queryFn: () => plannerApi.day(date), placeholderData: keepPreviousData });

export const useMonth = (month: string) =>
  useQuery({ queryKey: plannerKeys.month(month), queryFn: () => plannerApi.month(month), placeholderData: keepPreviousData });

export const useHabits = () => useQuery({ queryKey: plannerKeys.habits, queryFn: plannerApi.habits });

type Toggle = { habitId: string; frequency: Frequency; date: string; checked: boolean };

/** Ticks or unticks a habit for the period containing `date`, updating every cached view first. */
export function useToggleCheck() {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: ({ habitId, frequency, date, checked }: Toggle) => {
      const period = periodFor(frequency, date);
      return checked ? plannerApi.tick(habitId, period) : plannerApi.untick(habitId, period);
    },
    onMutate: async ({ habitId, frequency, date, checked }: Toggle) => {
      await qc.cancelQueries({ queryKey: plannerKeys.all });
      const period = periodFor(frequency, date);
      const snapshot = qc.getQueriesData({ queryKey: plannerKeys.all });
      qc.setQueriesData<DayView>({ queryKey: ["planner", "day"] }, (d) => {
        if (!d || periodFor(frequency, d.date) !== period) return d;
        const flip = (list: DayView["habits"]["daily"]) => list.map((h) => (h.id === habitId ? { ...h, checked } : h));
        return { ...d, habits: { daily: flip(d.habits.daily), weekly: flip(d.habits.weekly), monthly: flip(d.habits.monthly) } };
      });
      qc.setQueriesData<MonthView>({ queryKey: ["planner", "month"] }, (m) => {
        if (!m) return m;
        return {
          ...m,
          daily: m.daily.map((r) =>
            r.habit.id !== habitId ? r : { ...r, checks: checked ? [...new Set([...r.checks, period])] : r.checks.filter((c) => c !== period) },
          ),
          weekly: m.weekly.map((r) =>
            r.habit.id !== habitId ? r : { ...r, weeks: r.weeks.map((w) => (w.monday === period ? { ...w, checked } : w)) },
          ),
          monthly: m.monthly.map((r) => (r.habit.id === habitId && `${m.month}-01` === period ? { ...r, checked } : r)),
        };
      });
      return { snapshot };
    },
    onError: (err, _v, ctx) => {
      ctx?.snapshot.forEach(([key, data]) => qc.setQueryData(key, data));
      toast.error(err.message);
    },
    // Percentages and streaks come from the server.
    onSettled: () => qc.invalidateQueries({ queryKey: plannerKeys.all }),
  });
}

export function useSaveTasks() {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: ({ date, tasks }: { date: string; tasks: { text: string; done: boolean }[] }) => plannerApi.putTasks(date, tasks),
    onSuccess: (tasks, { date }) => qc.setQueryData<DayView>(plannerKeys.day(date), (d) => (d ? { ...d, tasks } : d)),
    onError: (err) => toast.error(err.message),
  });
}

export function useUpdateTask() {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: ({ id, done }: { id: string; done: boolean; date: string }) => plannerApi.updateTask(id, { done }),
    onMutate: async ({ id, done, date }) => {
      await qc.cancelQueries({ queryKey: plannerKeys.day(date) });
      const previous = qc.getQueryData<DayView>(plannerKeys.day(date));
      qc.setQueryData<DayView>(plannerKeys.day(date), (d) => (d ? { ...d, tasks: d.tasks.map((t) => (t.id === id ? { ...t, done } : t)) } : d));
      return { previous };
    },
    onError: (err, { date }, ctx) => {
      if (ctx?.previous) qc.setQueryData(plannerKeys.day(date), ctx.previous);
      toast.error(err.message);
    },
  });
}

/** For the manage dialog: no optimistic edit, just refresh everything planner-related. */
export function usePlannerAction<V>(fn: (v: V) => Promise<unknown>, success?: string) {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: fn,
    onSuccess: () => success && toast.success(success),
    onError: (err) => toast.error(err.message),
    onSettled: () => qc.invalidateQueries({ queryKey: plannerKeys.all }),
  });
}
```

```tsx
function TopThree({ day }: { day: DayView }) {
  const save = useSaveTasks();
  const toggle = useUpdateTask();
  const [drafts, setDrafts] = useState(() => slots(day));
  // Reset only when the saved tasks change, so a background refetch (e.g. after ticking a habit)
  // never wipes what the user is typing.
  const savedKey = JSON.stringify(day.tasks.map((t) => [t.text, t.done]));
  useEffect(() => setDrafts(slots(day)), [savedKey]); // eslint-disable-line react-hooks/exhaustive-deps

  function commit() {
    const tasks = drafts.filter((t) => t.text.trim()).map((t) => ({ text: t.text.trim(), done: t.done }));
    const current = day.tasks.map((t) => ({ text: t.text, done: t.done }));
    if (JSON.stringify(tasks) !== JSON.stringify(current)) save.mutate({ date: day.date, tasks });
  }

  return (
    <div className="grid content-start gap-2">
      <h3 className="text-xs font-medium uppercase tracking-wide text-muted-foreground">Top 3</h3>
      {drafts.map((t, i) => {
        const saved = day.tasks[i];
        return (
          <div key={i} className="flex items-center gap-2">
            <TickBox
              checked={t.done}
              disabled={!saved}
              label={saved ? `Mark "${saved.text}" ${t.done ? "not done" : "done"}` : "Write a task first"}

              onChange={(e) => setDrafts((all) => all.map((x, j) => (j === i ? { ...x, text: e.target.value } : x)))}
              onBlur={commit}
              onKeyDown={(e) => e.key === "Enter" && e.currentTarget.blur()}
              placeholder={i === 0 ? "Most important thing today" : "Optional"}

              aria-label={`Top ${i + 1}`}
              className={cn("h-9", t.done && "text-muted-foreground line-through")}
            />
          </div>
        );
      })}
    </div>
  );
}
```

```tsx
          <Input value={name} onChange={(e) => setName(e.target.value)} placeholder={`New ${frequency} habit`} maxLength={80} aria-label="New habit name" />
          <Button type="submit" variant="secondary" disabled={!name.trim() || create.isPending}>
            Add
          </Button>
        </form>
        {archived.length > 0 && (
          <div className="grid gap-2 border-t border-border/70 pt-4">
            <p className="text-xs text-muted-foreground">Archived (history kept)</p>
            {archived.map((h) => (
              <ArchivedHabit key={h.id} habit={h} />
            ))}
          </div>
        )}
      </DialogContent>
    </Dialog>
  );
}

function HabitEditor({ habit, above, below }: { habit: HabitRow; above?: HabitRow; below?: HabitRow }) {
  const [name, setName] = useState(habit.name);
  const rename = usePlannerAction((n: string) => plannerApi.updateHabit(habit.id, { name: n }));
  const archive = usePlannerAction(() => plannerApi.updateHabit(habit.id, { archived: true }), `${habit.name} archived`);
  const swap = usePlannerAction(async (other: HabitRow) => {
    await plannerApi.updateHabit(habit.id, { sortOrder: other.sortOrder });
    await plannerApi.updateHabit(other.id, { sortOrder: habit.sortOrder });
  });

  function saveName() {
    const n = name.trim();
    if (!n) return setName(habit.name);
    if (n !== habit.name) rename.mutate(n, { onError: () => setName(habit.name) });
  }

  return (
    <li className="flex items-center gap-1.5">
      <Input
        value={name}
        onChange={(e) => setName(e.target.value)}
        onBlur={saveName}
        onKeyDown={(e) => e.key === "Enter" && e.currentTarget.blur()}
        maxLength={80}
        className="h-8"
        aria-label={`Rename ${habit.name}`}
      />
      <Button variant="ghost" size="icon-sm" disabled={!above} onClick={() => above && swap.mutate(above)} aria-label={`Move ${habit.name} up`}>
        <ArrowUp />
      </Button>
      <Button variant="ghost" size="icon-sm" disabled={!below} onClick={() => below && swap.mutate(below)} aria-label={`Move ${habit.name} down`}>
        <ArrowDown />
      </Button>
      <Button variant="ghost" size="sm" onClick={() => archive.mutate(undefined)} className="text-muted-foreground">
        Archive
      </Button>
    </li>
  );
}

function ArchivedHabit({ habit }: { habit: HabitRow }) {
  const [confirming, setConfirming] = useState(false);
  const restore = usePlannerAction(() => plannerApi.updateHabit(habit.id, { archived: false }), `${habit.name} restored`);
  const remove = usePlannerAction(() => plannerApi.deleteHabit(habit.id), `${habit.name} deleted`);
  return (
    <div className="flex items-center justify-between gap-2 text-sm">
      <span className="min-w-0 truncate text-muted-foreground">{habit.name}</span>
      <div className="flex gap-1">
        <Button variant="ghost" size="sm" onClick={() => restore.mutate(undefined)}>
          Restore
        </Button>
        {confirming ? (
          <Button variant="ghost" size="sm" className="text-destructive" onClick={() => remove.mutate(undefined)}>
            Delete with history
          </Button>
        ) : (
          <Button variant="ghost" size="sm" className="text-muted-foreground hover:text-destructive" onClick={() => setConfirming(true)}>
            Delete
          </Button>
        )}
      </div>
    </div>
  );
}
```
