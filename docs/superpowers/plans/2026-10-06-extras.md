# Extras Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship five per-person extras (Today on Home, forgiving streaks, wins, want list, Hermes nudges), all off by default and toggled on the People page, plus always-on quick wins.

**Architecture:** Extras are strings stored in the existing `users.features` JSON array. They're resolved by `effectiveExtras` and exposed as `c.get("extras")` and `/api/me.extras`. Each extra's logic is a pure, unit-tested module in `shared/` (`planner.ts`, `wins.ts`, `briefing.ts`, `money.ts`) plus a thin D1 service and a route. The UI shows an extra only when `useHasExtra(extra)` is true. One new table: `wants`.

**Tech Stack:** Hono, Drizzle + D1, Zod 4, Vitest, React 19 + TanStack Query, Tailwind, Phosphor icons, sharp (icons), Python 3 stdlib (Hermes).

**Spec:** `docs/superpowers/specs/2026-10-06-extras-design.md`

## Global Constraints

- Extras: `home_today`, `kind_streaks`, `wins`, `wants`, `nudges`. Default off. An extra works only while its required section is on (`home_today`/`kind_streaks`/`wins` need `planner`; `wants` needs `money`; `nudges` needs none).
- The admin gets only the extras stored for them. The admin may PATCH their own `extras`, but never their own `features` (400 `admin_has_all`).
- An extra that's off must change nothing: no UI and no data. Its routes return 403 `extra_disabled`, except briefing, which returns `{ message: "" }`.
- Want wait: `< 5000` cents waits 24 h; `<= 20000` waits 72 h; else 168 h.
- Forgiving streak: a single missed period is skipped, two in a row end the streak, and an open current period isn't a miss. Monthly habits have no streak.
- No-spend day: a day up to today, on or after the person's first ever expense, with no expense except bill expenses (`recurring_bill_id` not null).
- Dates are Berlin calendar dates and weeks start on Monday, as in the Planner.
- Every query filters by `user_id`. Another user's id gives 404.
- The look stays as it is: dark, emerald `primary`, the `panel` card, warnings `text-status-warning` with a label (never colour alone).
- Write files containing backslashes with the Write/Edit tools, not shell heredocs.

## Review Focus

1. Toggling a section on the People page must not wipe that person's extras, and the reverse. PATCH merges. Pinned in Task 1 isolation checks.
2. A brand-new user with no expenses must not get "7 no-spend days". Counting starts at the first expense. Pinned in Task 8 unit tests.
3. A bill due tomorrow when tomorrow is the 1st of next month must still appear in the morning brief. Pinned in Task 9 unit and service code (next month's overview).
4. Buying a want twice (double tap or retry) must create one expense, not two. Pinned in Task 6 isolation checks (second buy is 409).
5. A habit missed yesterday but ticked the day before must show at risk with the streak kept, not 0. Pinned in Task 4 unit and isolation checks.

```ts
/** Small optional helpers inside sections. Off by default, switched on per person (admin too). */
export const EXTRAS = ["home_today", "kind_streaks", "wins", "wants", "nudges"] as const;
export type Extra = (typeof EXTRAS)[number];

export const EXTRA_LABELS: Record<Extra, string> = {
  home_today: "Today on Home",
  kind_streaks: "Forgiving streaks",
  wins: "Wins",
  wants: "Want list",
  nudges: "Hermes nudges",
};

/** The section an extra lives in. It only works while that section is on. */
export const EXTRA_REQUIRES: Record<Extra, Feature | null> = {
  home_today: "planner",
  kind_streaks: "planner",
  wins: "planner",
  wants: "money",
  nudges: null,
};

export const isExtra = (v: unknown): v is Extra => typeof v === "string" && (EXTRAS as readonly string[]).includes(v);

/** Stored extras that can work right now, given the person's sections. */
export function effectiveExtras(stored: readonly string[], sections: readonly Feature[]): Extra[] {
  return EXTRAS.filter((e) => stored.includes(e) && (EXTRA_REQUIRES[e] === null || sections.includes(EXTRA_REQUIRES[e]!)));
}
```

```ts
import { asc, eq } from "drizzle-orm";
import { Hono } from "hono";
import { z } from "zod";
import { users } from "../../../db/schema";
import { EXTRAS, FEATURES, effectiveFeatures } from "../../../shared/features";
import { isOwner } from "../auth/users";
import { getDb } from "../db";
import type { AppEnv } from "../env";
import { ApiError, notFound } from "../errors";
import { validate } from "../validate";

const accessSchema = z
  .object({
    features: z.array(z.enum(FEATURES)).max(FEATURES.length).optional(),
    extras: z.array(z.enum(EXTRAS)).max(EXTRAS.length).optional(),
  })
  .refine((b) => b.features !== undefined || b.extras !== undefined, "Send features or extras");

const storedExtras = (stored: readonly string[]) => EXTRAS.filter((e) => stored.includes(e));

/** People and what they can use. Mounted behind requireAdmin. */
export const adminRoutes = new Hono<AppEnv>()
  .get("/users", async (c) => {
    const rows = await getDb(c.env.DB).select().from(users).orderBy(asc(users.createdAt));
    const people = rows.map((u) => {
      const isAdmin = isOwner(u.email, c.env.OWNER_EMAIL);
      return {
        id: u.id,
        email: u.email,
        createdAt: u.createdAt,
        isAdmin,
        features: effectiveFeatures(isAdmin, u.features),
        extras: storedExtras(u.features),
      };
    });
    // Admin first, then everyone else in the order they joined.
    return c.json({ users: people.sort((a, b) => Number(b.isAdmin) - Number(a.isAdmin)) });
  })
  .patch("/users/:id", validate("json", accessSchema), async (c) => {
    const db = getDb(c.env.DB);
    const user = await db.select().from(users).where(eq(users.id, c.req.param("id"))).get();
    if (!user) throw notFound("Person");
    const isAdmin = isOwner(user.email, c.env.OWNER_EMAIL);
    const body = c.req.valid("json");
    if (isAdmin && body.features !== undefined) {
      throw new ApiError(400, "admin_has_all", "The admin always has every section");
    }
    // Merge: changing sections keeps extras, and changing extras keeps sections.
    const sections = body.features ? [...new Set(body.features)] : FEATURES.filter((f) => user.features.includes(f));
    const extras = body.extras ? [...new Set(body.extras)] : storedExtras(user.features);
    await db.update(users).set({ features: [...sections, ...extras] }).where(eq(users.id, user.id));
    return c.json({
      user: { id: user.id, email: user.email, createdAt: user.createdAt, isAdmin, features: effectiveFeatures(isAdmin, sections), extras },
    });
  });
```

```ts
/**
 * "Never miss twice": like `streak`, but a single missed period between ticks is skipped
 * (it doesn't count and doesn't break). Two misses in a row end it.
 */
export function kindStreak(f: Frequency, checked: ReadonlySet<string>, today: string): number {
  if (f === "monthly" || checked.size === 0) return 0;
  const step = f === "daily" ? 1 : 7;
  const earliest = [...checked].reduce((a, b) => (a < b ? a : b));
  let p = periodFor(f, today);
  if (!checked.has(p)) p = addDays(p, -step);
  let n = 0;
  let misses = 0;
  while (p >= earliest) {
    if (checked.has(p)) {
      n++;
      misses = 0;
    } else if (++misses === 2) {
      break;
    }
    p = addDays(p, -step);
  }
  return n;
}

/** The previous period was missed, the current one is still open, and the streak is still alive. */
export function atRisk(f: Frequency, checked: ReadonlySet<string>, today: string): boolean {
  if (f === "monthly") return false;
  const step = f === "daily" ? 1 : 7;
  const current = periodFor(f, today);
  const previous = addDays(current, -step);
  return !checked.has(current) && !checked.has(previous) && checked.has(addDays(previous, -step));
}
```

```ts
// The want list: a cooling-off queue for impulse buys. Buying logs a normal expense.

const strip = <T extends { userId: string }>({ userId: _owner, ...rest }: T) => rest as WantRow;
const where = (userId: string, id: string) => and(eq(wants.id, id), eq(wants.userId, userId));

async function getWant(db: Db, userId: string, id: string): Promise<WantRow> {
  const row = await db.select().from(wants).where(where(userId, id)).get();
  if (!row) throw notFound("Want");
  return strip(row);
}

function assertWaiting(w: WantRow) {
  if (w.status !== "waiting") throw new ApiError(409, "already_decided", `${w.name} was already ${w.status}`);
}

export async function savedCents(db: Db, userId: string): Promise<number> {
  const row = await db
    .select({ total: sql<number>`coalesce(sum(${wants.priceCents}), 0)` })
    .from(wants)
    .where(and(eq(wants.userId, userId), eq(wants.status, "skipped")))
    .get();
  return Number(row?.total ?? 0);
}

export async function listWants(db: Db, userId: string): Promise<WantsView> {
  const rows = (await db.select().from(wants).where(eq(wants.userId, userId)).orderBy(desc(wants.createdAt))).map(strip);
  return {
    waiting: rows.filter((w) => w.status === "waiting").sort((a, b) => a.readyAt.localeCompare(b.readyAt)),
    decided: rows.filter((w) => w.status !== "waiting").sort((a, b) => (b.decidedAt ?? "").localeCompare(a.decidedAt ?? "")).slice(0, 20),
    savedCents: await savedCents(db, userId),
  };
}

export async function createWant(db: Db, userId: string, input: WantCreate, now = new Date()): Promise<WantRow> {
  const row = {
    id: crypto.randomUUID(),
    userId,
    name: input.name,
    priceCents: input.priceCents,
    url: input.url || null,
    createdAt: now.toISOString(),
    readyAt: new Date(now.getTime() + waitHours(input.priceCents) * 3600_000).toISOString(),
    status: "waiting" as const,
    decidedAt: null,
    expenseId: null,
  };
  await db.insert(wants).values(row);
  return strip(row);
}

export async function buyWant(db: Db, userId: string, id: string, input: WantBuy, now = new Date()) {
  const w = await getWant(db, userId, id);
  assertWaiting(w);
  // Claim it first, so a double tap can't log two expenses.
  const claimed = await db
    .update(wants)
    .set({ status: "bought", decidedAt: now.toISOString() })
    .where(and(where(userId, id), eq(wants.status, "waiting")))
    .returning()
    .get();
  if (!claimed) throw new ApiError(409, "already_decided", `${w.name} was already decided`);
  try {
    const expense = await createExpense(db, userId, {
      categoryId: input.categoryId,
      amountCents: input.priceCents ?? w.priceCents,
      spentOn: input.spentOn ?? berlinToday(now),
      note: w.name,
    });
    await db.update(wants).set({ expenseId: expense.id }).where(where(userId, id));
    return { want: { ...strip(claimed), expenseId: expense.id }, expenseId: expense.id };
  } catch (err) {
    // The category was wrong or gone: put the want back so it can be bought again.
    await db.update(wants).set({ status: "waiting", decidedAt: null }).where(where(userId, id));
    throw err;
  }
}

export async function skipWant(db: Db, userId: string, id: string, now = new Date()): Promise<WantRow> {
  const w = await getWant(db, userId, id);
  assertWaiting(w);
  await db.update(wants).set({ status: "skipped", decidedAt: now.toISOString() }).where(where(userId, id));
  return { ...w, status: "skipped", decidedAt: now.toISOString() };
}

export async function deleteWant(db: Db, userId: string, id: string) {
  await getWant(db, userId, id);
  await db.delete(wants).where(where(userId, id));
}

export async function readyWants(db: Db, userId: string, now = new Date()): Promise<WantRow[]> {
  return (await listWants(db, userId)).waiting.filter((w) => w.readyAt <= now.toISOString());
}

export async function skippedBetween(db: Db, userId: string, fromIso: string, toIso: string): Promise<WantRow[]> {
  return (await db.select().from(wants).where(and(eq(wants.userId, userId), eq(wants.status, "skipped"))))
    .map(strip)
    .filter((w) => w.decidedAt !== null && w.decidedAt >= fromIso && w.decidedAt < toIso);
}

async function findWaiting(db: Db, userId: string, name: string): Promise<WantRow> {
```

```ts
import { addDays, type Frequency } from "./planner";

export type WinsView = {
  week: string;
  days: string[];
  today: string;
  tasksDone: { day: string; text: string }[];
  habits: { name: string; frequency: Frequency; count: number }[];
  dailyPercent: number | null;
  shipped: { project: string; note: string | null; day: string }[] | null;
  noSpendDays: string[] | null;
  skipped: { name: string; priceCents: number; day: string }[] | null;
  total: number;
};

export const weekDays = (monday: string) => Array.from({ length: 7 }, (_, i) => addDays(monday, i));

/** Days up to today, on or after the first expense ever, with no spending except bills. */
export function noSpendDays(days: string[], spendDays: ReadonlySet<string>, today: string, since: string | null): string[] {
  if (since === null) return [];
  return days.filter((d) => d <= today && d >= since && !spendDays.has(d));
}

/** Share of daily-habit ticks over the week's elapsed days, counting each habit from its first day. */
export function weekHabitPercent(habits: { createdOn: string; checks: ReadonlySet<string> }[], days: string[], today: string): number | null {
  let possible = 0;
  let done = 0;
  for (const h of habits) {
    for (const d of days) {
      if (d > today || d < h.createdOn) continue;
      possible++;
      if (h.checks.has(d)) done++;
    }
  }
  return possible === 0 ? null : Math.round((100 * done) / possible);
}

export function winsTotal(w: {
  tasksDone: unknown[];
  habits: { count: number }[];
  shipped: unknown[] | null;
  noSpendDays: unknown[] | null;
  skipped: unknown[] | null;
}): number {
  return (
    w.tasksDone.length +
    w.habits.reduce((n, h) => n + h.count, 0) +
    (w.shipped?.length ?? 0) +
    (w.noSpendDays?.length ?? 0) +
    (w.skipped?.length ?? 0)
  );
}
```

```ts
export async function getWins(

  const monday = opts.week ?? mondayOf(today);

  const days = weekDays(monday);
  const [first, last] = [days[0], days[6]];

  const [tasks, habitRows, checkRows] = await db.batch([
    db
      .select({ day: dayTasks.day, text: dayTasks.text })
      .from(dayTasks)
      .where(and(eq(dayTasks.userId, userId), between(dayTasks.day, first, last), eq(dayTasks.done, true)))
      .orderBy(asc(dayTasks.day), asc(dayTasks.position)),
    db.select().from(habits).where(and(eq(habits.userId, userId), eq(habits.archived, false))),
    db
      .select({ habitId: habitChecks.habitId, period: habitChecks.period })
      .from(habitChecks)
      .where(and(eq(habitChecks.userId, userId), between(habitChecks.period, first, last))),
  ]);

  const byHabit = new Map<string, Set<string>>();
  for (const c of checkRows) byHabit.set(c.habitId, (byHabit.get(c.habitId) ?? new Set()).add(c.period));
  const counted = habitRows.filter((h) => h.frequency !== "monthly");
  const habitWins = counted
    .map((h) => ({ name: h.name, frequency: h.frequency, count: byHabit.get(h.id)?.size ?? 0 }))
    .filter((h) => h.count > 0)
    .sort((a, b) => b.count - a.count || a.name.localeCompare(b.name));
  const dailyPercent = weekHabitPercent(
    counted.filter((h) => h.frequency === "daily").map((h) => ({ createdOn: createdDay(h.createdAt), checks: byHabit.get(h.id) ?? new Set() })),
    days,
    today,
  );

  let shipped: WinsView["shipped"] = null;
  if (opts.sections.includes("projects")) {
    // shipped_at is UTC; widen by a day each side, then keep the Berlin days in the week.
    const rows = await db
      .select({ project: projects.name, note: shippedEvents.note, shippedAt: shippedEvents.shippedAt })
      .from(shippedEvents)
      .innerJoin(projects, eq(projects.id, shippedEvents.projectId))
      .where(and(eq(shippedEvents.userId, userId), between(shippedEvents.shippedAt, addDays(first, -1), addDays(last, 2))));
    shipped = rows.map((r) => ({ project: r.project, note: r.note, day: dayOf(r.shippedAt) })).filter((r) => r.day >= first && r.day <= last);
  }

  let noSpend: string[] | null = null;
  if (opts.sections.includes("money")) {
    const [spent, firstEver] = await db.batch([
      db
        .select({ day: expenses.spentOn })
        .from(expenses)
        .where(and(eq(expenses.userId, userId), between(expenses.spentOn, first, last), isNull(expenses.recurringBillId))),

  }

  const view = { week: monday, days, today, tasksDone: tasks, habits: habitWins, dailyPercent, shipped, noSpendDays: noSpend, skipped };
  return { ...view, total: winsTotal(view) };
}
```

```ts
import { formatEuro } from "./money";
import type { Frequency } from "./planner";

type Habit = { name: string; checked: boolean; streak: number; atRisk: boolean; frequency: Frequency };

export type BriefingInput = {
  today: string;
  tomorrow: string;
  /** null when Planner is off */
  tasks: { text: string; done: boolean }[] | null;
  daily: Habit[];
  weekly: Habit[];
  monthly: Habit[];
  /** null when Money is off; upcoming (unlogged) bills due today or tomorrow */
  bills: { name: string; amountCents: number; dueOn: string }[] | null;
  /** null when the Want list is off */
  readyWants: { name: string; priceCents: number }[] | null;
  /** null when Planner is off */
  wins: {
    total: number;
    tasksDone: number;
    habits: { name: string; count: number; frequency: Frequency }[];
    shipped: string[];
    noSpendDays: number;
    dailyPercent: number | null;
  } | null;
  leftCents: number | null;
  savedCents: number | null;
};

const names = (xs: { name: string }[]) => xs.map((x) => x.name).join(", ");

export function morningMessage(i: BriefingInput): string {
  const lines: string[] = [];
  if (i.tasks) {
    lines.push(
      i.tasks.length === 0
        ? 'Top 3: not set yet — reply "top 3: …".'
        : `Top 3: ${i.tasks.map((t) => (t.done ? `${t.text} (done)` : t.text)).join(", ")}.`,
    );
  }
  const habitParts = [
    [i.daily, "Habits today"],
    [i.weekly, "This week"],
    [i.monthly, "This month"],
  ]
    .map(([list, label]) => [(list as Habit[]).filter((h) => !h.checked), label] as const)
    .filter(([open]) => open.length > 0)
    .map(([open, label]) => `${label}: ${names(open)}.`);
  if (habitParts.length > 0) lines.push(habitParts.join(" "));
  if (i.bills && i.bills.length > 0) {
    const sorted = [...i.bills].sort((a, b) => a.dueOn.localeCompare(b.dueOn));
    lines.push(`Bills: ${sorted.map((b) => `${b.name} ${formatEuro(b.amountCents)} due ${b.dueOn === i.today ? "today" : "tomorrow"}`).join(", ")}.`);
  }
  if (i.readyWants && i.readyWants.length > 0) {
    lines.push(`Ready to decide: ${i.readyWants.map((w) => `${w.name} (${formatEuro(w.priceCents)})`).join(", ")}.`);
  }
  if (lines.length === 0) return "Good morning. Nothing scheduled, enjoy the day.";
  return [`Good morning. ${lines[0]}`, ...lines.slice(1)].join("\n");
}

export function eveningMessage(i: BriefingInput): string {
  if (!i.tasks) return "";
  const lines: string[] = [];
  const open = i.tasks.filter((t) => !t.done);
  if (open.length > 0) lines.push(`Top 3 still open: ${open.map((t) => t.text).join(", ")}.`);
  const left = i.daily.filter((h) => !h.checked);
  if (left.length > 0) lines.push(`Habits left: ${names(left)}.`);
  for (const h of [...i.daily, ...i.weekly]) {
    if (!h.atRisk || h.checked) continue;
    lines.push(
      h.frequency === "weekly"
        ? `${h.name} missed last week, tick this week to keep ${h.streak}.`
        : `${h.name} missed yesterday, tick today to keep ${h.streak}.`,
    );
  }
  return lines.length === 0 ? "" : ["Evening check.", ...lines].join("\n");
}

export function weeklyMessage(i: BriefingInput): string {
  const lines: string[] = [];
  const w = i.wins;
  if (w) {
    if (w.total === 0) {
      lines.push("Week in review: a quiet week. New week, fresh start.");
    } else {
      const parts: string[] = [];
      if (w.tasksDone > 0) parts.push(`Top 3 done ${w.tasksDone}×`);
      for (const h of w.habits.slice(0, 3)) parts.push(h.frequency === "weekly" ? `${h.name} ✓` : `${h.name} ${h.count}/7`);
      if (w.shipped.length > 0) parts.push(`shipped ${w.shipped.join(", ")}`);
      if (w.noSpendDays > 0) parts.push(`${w.noSpendDays} no-spend day${w.noSpendDays === 1 ? "" : "s"}`);
      lines.push(`Week in review: ${w.total} wins. ${parts.join(", ")}.`);
      if (w.dailyPercent !== null) lines.push(`Daily habits: ${w.dailyPercent}% of the week.`);
    }
  }
  const money: string[] = [];
  if (i.leftCents !== null) {
    money.push(i.leftCents >= 0 ? `${formatEuro(i.leftCents)} left this month.` : `${formatEuro(-i.leftCents)} over this month.`);
  }
  if (i.savedCents !== null && i.savedCents > 0) money.push(`Saved by waiting: ${formatEuro(i.savedCents)}.`);
  if (money.length > 0) lines.push(`Money: ${money.join(" ")}`);
  return lines.join("\n");
}
```

```ts
import { getWins } from "./wins";

export type BriefingKind = "morning" | "evening" | "weekly";

/** The text for one nudge, or "" to stay silent (also when the person hasn't switched nudges on). */
export async function getBriefing(
  db: Db,
  userId: string,
  kind: BriefingKind,
  ctx: { sections: readonly Feature[]; extras: readonly Extra[]; now?: Date },
): Promise<string> {
  if (!ctx.extras.includes("nudges")) return "";
  const now = ctx.now ?? new Date();
  const today = berlinToday(now);
  const tomorrow = addDays(today, 1);
  const planner = ctx.sections.includes("planner");
  const money = ctx.sections.includes("money");
  const wantsOn = ctx.extras.includes("wants");

  const day = planner ? await getDay(db, userId, today, now, ctx.extras.includes("kind_streaks")) : null;
  const habit = (h: { name: string; checked: boolean; streak: number; atRisk: boolean; frequency: "daily" | "weekly" | "monthly" }) => ({
    name: h.name,
    checked: h.checked,
    streak: h.streak,
    atRisk: h.atRisk,
    frequency: h.frequency,
  });

  let bills: BriefingInput["bills"] = null;
  let leftCents: number | null = null;
  if (money) {
    const month = berlinMonth(now);
    const o = await getOverview(db, userId, month, now);
    leftCents = o.totals.leftCents;
    const all = [...o.bills];
    // Tomorrow can be the 1st of next month.
    if (tomorrow.slice(0, 7) !== month) all.push(...(await getOverview(db, userId, addMonths(month, 1), now)).bills);
    bills = all
      .filter((b) => b.status === "upcoming" && (b.dueOn === today || b.dueOn === tomorrow))
      .map((b) => ({ name: b.name, amountCents: b.amountCents, dueOn: b.dueOn }));
  }

  let wins: BriefingInput["wins"] = null;
  if (kind === "weekly" && planner) {
    const w = await getWins(db, userId, { now, sections: ctx.sections, extras: ctx.extras });
    wins = {
      total: w.total,
      tasksDone: w.tasksDone.length,
      habits: w.habits,
      shipped: (w.shipped ?? []).map((s) => s.project),
      noSpendDays: w.noSpendDays?.length ?? 0,
      dailyPercent: w.dailyPercent,
    };
  }

  const input: BriefingInput = {
    today,
    tomorrow,
    tasks: day ? day.tasks.map((t) => ({ text: t.text, done: t.done })) : null,
    daily: day ? day.habits.daily.map(habit) : [],
    weekly: day ? day.habits.weekly.map(habit) : [],
    monthly: day ? day.habits.monthly.map(habit) : [],
    bills,
    readyWants: wantsOn && money ? (await readyWants(db, userId, now)).map((w) => ({ name: w.name, priceCents: w.priceCents })) : null,
    wins,
    leftCents: kind === "weekly" ? leftCents : null,
    savedCents: kind === "weekly" && wantsOn && money ? await savedCents(db, userId) : null,
  };
  if (kind === "morning") return morningMessage(input);
  if (kind === "evening") return eveningMessage(input);
  return weeklyMessage(input);
}
```

Ruling allowed: if `getOverview`'s bill `status` for a future month marks bills differently, check `billsForMonth` and adjust the filter. The rule is "not yet logged". Note it in the ledger.

```python
#!/usr/bin/env python3
"""Hermes cron script: prints Life Board's morning brief, or nothing (Hermes then stays silent).

Hermes cron scripts don't inherit ~/.hermes/.env, so this reads it directly.
Install: copy into ~/.hermes/scripts/ and run
  hermes cron create "0 8 * * *" --no-agent --script life_board_morning.py --deliver telegram --name life-board-morning
"""
import json
import os
import pathlib
import urllib.request

KIND = "morning"


def setting(name):
    if os.environ.get(name):
        return os.environ[name]
    env = pathlib.Path(os.environ.get("HERMES_HOME", pathlib.Path.home() / ".hermes")) / ".env"
    try:
        for line in env.read_text(encoding="utf-8").splitlines():
            key, _, value = line.partition("=")
            if key.strip() == name:
                return value.strip().strip('"').strip("'")
    except OSError:
        pass
    return ""


def main():
    base, token = setting("LIFE_BOARD_URL").rstrip("/"), setting("LIFE_BOARD_TOKEN")
    if not base or not token:
        print("Life Board: set LIFE_BOARD_URL and LIFE_BOARD_TOKEN in ~/.hermes/.env")
        return
    req = urllib.request.Request(f"{base}/api/agent/briefing/{KIND}", headers={"Authorization": f"Bearer {token}"})
    try:
        with urllib.request.urlopen(req, timeout=20) as res:
            message = json.loads(res.read().decode("utf-8")).get("message", "")
    except Exception as e:  # noqa: BLE001 - one line to Telegram beats a silent failure
        print(f"Life Board unreachable: {e}")
        return
    if message:
        print(message)


if __name__ == "__main__":
    main()
```
